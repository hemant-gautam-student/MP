# Mathematical Programming Solver

A Flask-based web application for solving Linear Programming and Transportation Problems using Graphical Method, Simplex Method, and Transportation Optimization techniques.

---

## 🚀 Overview

This project was built to simplify solving mathematical programming and optimization problems through an interactive web interface.

The application allows users to:

- Solve Linear Programming problems visually
- Generate feasible region graphs
- Solve optimization problems using the Simplex Method
- Solve Transportation Problems using Linear Programming
- Interact with a responsive and user-friendly UI

---

## ✨ Features

- Graphical Method Solver with feasible region visualization
- Simplex Method calculator
- Transportation Problem solver
- Dynamic constraint generation
- Interactive graph rendering
- Responsive sidebar navigation
- Dark mode support
- Real-time result rendering using AJAX & JSON APIs
